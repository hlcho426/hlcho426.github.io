생성 도구에서 잘 보이는 3D 캐릭터를 게임에 넣으면 곧바로 움직일까? Meshy의 10월 12일 가이드는 모델 생성 뒤에도 파일 내보내기, 애니메이션 이름 연결, 충돌 규칙 설정이 필요하다는 작업 흐름을 보여 준다.

## 무슨 일이 있었나
{:.briefing-heading}

### 모델 생성 뒤에 남는 가져오기 작업

Meshy가 공개한 가이드는 자산 생성과 GDevelop의 게임 규칙 설정을 이어 작은 수집 게임을 만드는 절차다. GLB는 모델 표면의 형상인 메시, 텍스처, 뼈대와 동작을 한 파일에 담는 형식이다. 가이드는 메시를 다시 구성하는 리메시를 애니메이션 작업보다 먼저 수행하고, 추가한 동작을 단일 GLB로 내보내도록 안내한다.

### 애니메이션 이름과 충돌 판정이 연결 지점이다

가이드는 가져온 동작 이름을 Run·Idle·Jump·Fall에 맞추고, 달리기와 대기는 반복하도록 설정한다. 코인 수집에는 일반 충돌 조건이 아닌 3D 물리 충돌 조건을 사용한다. 이는 공급사가 설명하는 제작 절차다. 이 글에서는 해당 프로젝트를 실행하거나 생성 모델의 품질과 동작을 재현하지 않았다.

### 제작 작업은 어떻게 달라지나

편집자의 해석이다. 작업이 막히는 지점은 모델을 만드는 단계와 엔진이 그 파일을 사용하는 단계 사이에도 있다. 생성 결과를 확인한 뒤 엔진으로 넘길 동작 목록과 이름을 먼저 정하고, 가져오기 후 각 이름이 실제 클립에 연결됐는지 검사하는 흐름을 제안한다. 이후 이동·충돌·점수를 따로 확인하면, 잘못된 메시와 잘못된 게임 규칙을 구분하기 쉬울 수 있다. 이 이점은 아직 측정하지 않았다.

### 구체적인 작업 예시

**설명용 가상 시험이며 실제 실행 결과가 아니다.** 입력은 가상의 탐험가 GLB, 바닥, 코인 하나다. 처리 단계는 모델 가져오기 → 동작 이름 연결 → 이동과 충돌 설정 → 점수 변화 확인이다. 기대 결과는 정지할 때 대기 동작, 이동할 때 달리기 동작이 나타나고 코인 하나를 수집하면 점수가 한 번만 오르는 것이다. 달리는 동안 대기 동작이 나오거나, 코인이 사라졌는데 점수가 중복 증가하면 실패로 기록한다. 모델의 외관과 규칙의 성공 여부를 별도 항목으로 남긴다.

### 실제 사용 조건

AI는 자산 생성에 사용되고 게임 규칙은 엔진에서 구성하는 절차다. 원문은 계정과 브라우저 환경을 안내하며 다운로드 허용량이 요금제에 따라 달라진다고 밝힌다. 실제 계정별 권한·지역·다운로드 가능 여부는 확인하지 않았다.

### 확인된 범위와 한계

공급사 튜토리얼이며 독립 생산성 평가가 아니다. 생성 속도·게임 성능을 직접 측정하지 않았고, 비공개 데이터 처리 조건과 생성 자산의 구체적인 재사용 라이선스도 검증하지 않았다. 무료 생성과 필요한 파일의 다운로드 권한을 같은 조건으로 간주하지 않는다.

## 왜 중요한가
{:.briefing-heading}

**분석:** 도입 판단을 위한 해석이다. 모델이 보기 좋다는 평가만으로 게임 자산으로 쓸 수 있다고 판단하면, 가져오기 뒤에 발견하는 문제가 늘 수 있다. 반대로 동작 연결과 충돌 규칙을 먼저 정해 두면 생성 결과가 그 요구를 충족하는지 좁혀 살펴볼 수 있다. 작업 시간을 비교한다면 생성 대기 시간만 재지 말고, 파일을 수정하고 다시 가져오는 시간과 규칙을 검토하는 시간까지 포함해야 한다. 원문은 이러한 비교 실험의 결과를 제공하지 않는다.

### 어떤 개발자에게 관련 있나

생성한 3D 자산으로 짧은 이동·수집 프로토타입을 만들려는 개발자에게 관련 있다. 게임 규칙을 직접 구성하고 가져온 동작을 검토할 수 있다는 전제가 필요하다.

### 지금 도입할 만한가

판단은 제한된 시험이다. 이미 두 도구를 사용할 환경이 있다면 캐릭터 하나로 파일·동작·충돌 연결을 확인할 만하다. 가이드만으로 생성 품질이나 제작 시간 절감을 확정할 수 없어, 전체 아트 파이프라인 교체는 보류한다.

## 개발에 적용할 점
{:.briefing-heading}

- 편집자의 미검증 제안: 같은 시험 모델에서 대기·이동·점프 상태를 하나씩 호출하고, 요청한 상태와 실제 재생 동작이 일치하는지 기록한다. 이름 변경 전후의 차이도 남긴다.

- 편집자의 미검증 제안: 코인 하나에 여러 번 접근해 삭제와 점수 증가가 한 번만 일어나는지 확인한다. 모델 가져오기 성공과 수집 규칙 성공을 따로 판정한다.
