*이 글은 공개 원문을 바탕으로 Codex가 조사하고 정리했습니다.*

번역문이 길어져 메뉴 글자가 잘리면 문구와 화면 크기마다 다시 손을 봐야 한다. Godot 4.8 베타 안내는 글자 크기 자동 조절과 번역 상황을 흉내 내는 점검 기능을 소개한다. 두 기능을 함께 시험하되, 글자가 들어가는지와 읽을 수 있는지를 따로 판단해야 한다.

## 무슨 일이 있었나
{:.briefing-heading}

### 베타 공개는 새 기능 전체의 최초 발표일이 아니다

Godot 공식 글은 10월 15일 4.8 베타를 알리면서 기능 추가를 멈추고 회귀 오류 수정에 집중한다고 설명한다. 회귀는 이전에 되던 동작이 새 버전에서 깨지는 현상이다. dev 7 대비 새 기능은 없다고 명시하므로 아래 기능을 이날 처음 생긴 것으로 소개하지 않는다.

### 자동 크기 조절과 번역 점검을 연결한다

공식 GUI 설명은 Label과 RichTextLabel에 영역에 맞추는 글자 크기 기능과 auto_font_size·min_font_size·max_font_size 속성을 소개한다. Label은 화면의 글자 표시 요소다. 별도의 에디터 설명은 의사 현지화, 즉 번역 때 생길 변화를 흉내 내는 점검을 소개한다. 실제 번역의 정확성까지 검사한다는 뜻은 아니다.

### 제작 작업은 어떻게 달라지나

편집자의 적용 해석이다. 문구마다 글자 크기를 직접 고치던 흐름에서, 먼저 읽기 가능한 크기 범위를 정하고 자동 조절 뒤 예외 화면을 검토하는 흐름으로 바꿔 볼 수 있다. 의사 현지화로 문제 후보를 찾은 다음 실제 번역문으로 다시 확인한다. 자동 조절은 검토의 입력을 만들 뿐 읽기 품질을 대신 판정하지 않는다.

### 구체적인 작업 예시

설명용 가상 시험이며 실제 실행 결과가 아니다. 입력은 같은 폭의 퀘스트 제목 칸과 짧은 원문·긴 번역문이다. 처리에서는 허용할 글자 크기 범위를 정하고 자동 조절을 켜서 두 문구를 표시한다. 기대 결과는 누락 없이 읽히고 옆 아이콘과 겹치지 않는 화면이다. 최소 크기까지 줄어도 잘리거나 목표 화면에서 읽기 어렵다면 실패다. 해당 문구는 칸을 넓히거나 줄바꿈을 허용하는 별도 수정 후보로 남긴다.

### 실제 사용 조건

생성형 AI가 아닌 엔진 기능이다. 베타 복사본에서 확인할 대상이며 공식 안내상 C#용 .NET 빌드는 .NET 10 이상을 요구한다. 이 글에서는 엔진·SDK 설치나 기존 프로젝트 변환을 수행하지 않았다.

### 확인된 범위와 한계

공식 기능 안내를 확인했지만 자동 조절의 실제 화면·언어별 동작은 시험하지 않았다. 사전 공개 버전이므로 현재 프로젝트의 호환성과 안정성을 보장할 수 없다. 제작 시간 절감이나 가독성 개선 수치는 측정하지 않았다.

## 왜 중요한가
{:.briefing-heading}

**분석:** 편집자의 분석이다. 글자가 영역 안에 있다는 검사만 통과하면 작은 화면에서 지나치게 작아진 글자를 놓칠 수 있다. UI 변경을 검토할 때는 잘림·겹침과 최소 가독성을 서로 다른 실패 조건으로 남기는 편이 유용하다. 작업 시간을 비교하려면 같은 문구와 화면 조건으로 수정 시간 및 사람이 재검토한 시간을 함께 기록해야 한다. 기능 소개 자체는 그런 절감을 입증하지 않는다.

### 어떤 개발자에게 관련 있나

Godot에서 다국어 메뉴·퀘스트 UI를 만드는 개발자와 UI 작업자에게 관련 있다. 글자 표시 요소와 레이아웃을 수정하고 목표 화면에서 확인할 수 있어야 한다.

### 지금 도입할 만한가

판단은 시험이다. 이미 글자 잘림이 있는 화면의 복사본으로 범위를 제한한다. 읽기 기준을 충족하지 못하면 자동 조절을 확대 적용하지 말고 레이아웃부터 수정한다. 안정 버전 프로젝트 전체를 옮길 근거는 이번 안내만으로 부족하다.

## 개발에 적용할 점
{:.briefing-heading}

- 편집자의 미검증 제안: 같은 문구 집합을 좁은 화면과 넓은 화면에 표시하고 잘림·겹침·읽기 어려움을 각각 기록한다. 통과 기준은 시험 전에 정한다.

- 편집자의 미검증 제안: 기존 수동 조절과 자동 조절을 같은 번역문으로 비교한다. 수정 시간과 재검토 시간을 함께 남기고 실제 번역문 확인을 생략하지 않는다.
